## Benchmark: tsrs vs tsgo 7.0.2 vs bun check

Time and peak memory to type-check each project (`-p <project> --noEmit`) on Depot CI `depot-ubuntu-24.04-8` (8 vCPU, 31 GB RAM, Linux x86_64, AMD EPYC 9R45 96-Core Processor); the `--checkers 16` and default mode on the wider machine tables on Depot CI `depot-ubuntu-24.04-16` (16 vCPU, 63 GB RAM, Linux x86_64, AMD EPYC 9R45 96-Core Processor). Median of 5 interleaved runs (3 for tsgo) in the default mode, `--singleThreaded` and `--checkers 8` tables; median of 10 interleaved runs (3 for tsgo) in the `--checkers 16` and default mode on the wider machine tables.

- **tsrs**: commit `f31f5ee3937f`, PGO-optimized `dist` build, built like the npm release binaries.
- **tsgo**: npm `typescript@7.0.2`, the official Go compiler. tsrs ports a later 7.1-dev commit (`b85298b6`).
- **bun check**: Bun 1.4.4-canary.1+47ba1c8d8.

Projects: vscode, xstate-main, webpack, mui-docs, Compiler, Compiler-Unions are from [microsoft/typescript-benchmarking](https://github.com/microsoft/typescript-benchmarking), the suite the TypeScript team benchmarks tsgo on; the other 11 are large open-source applications.
