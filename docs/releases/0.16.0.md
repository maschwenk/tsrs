- **Package scope.** Native platform packages and WebAssembly move from `@ts-rs` to `@tsrs` (#512). The main package remains `tsrs` and selects its platform package automatically. Update direct platform and WebAssembly dependencies to the new scope.
- **Compiler optimizations.** Parser, binder, AST and checker changes reduce redundant work (#532, #533, #535, #547, #548, #549, #552, #554, #557). Conformance remains at the documented thresholds; no new packaged-release performance comparison is claimed.
- **Development tooling.** Removed the `alloc-profile` build feature, counting allocator, heap sampler and reachability census (#551). Arena recycling checks and the remaining memory reports are still available.

The TypeScript source pin is unchanged: `microsoft/TypeScript@b85298b6a81f`. Release binaries report the matching nightly `7.1.0-dev.20260930.4`.
