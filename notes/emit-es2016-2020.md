## Decisions
- Go `defer` restores: `objectRestSpreadTransformer.visit` restores `expressionResultIsUnused` after the dispatch
  `match`; the parameter-list scope is restored after each `Update*` call. Go shares the old map in
  `enterParameterListContext`; Rust moves the `Option<FxHashSet>` out and back (the set is never mutated after
  it is collected, so this is the same).
- `tx.Visitor().Visit(x)` (optionalcatch `node.Block`) calls the transformer's own `visit`.
- `collectObjectRestAssignments`/`visitCatchClause`: Go creates an empty `VariableDeclarationList` and appends to
  its `Declarations.Nodes`; Rust creates the list with the declarations (same node, same loc).
- `visitForOftatement`: Go's `else if node.Statement != nil` always holds; Rust takes the branch unconditionally.
